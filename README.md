# Sohan Hajra — Portfolio Website

Recruiter-facing static portfolio for quantitative research, research engineering, quantitative development, and systematic trading.

## Design goals

- Make the purpose obvious within seconds.
- Treat GitHub as the evidence layer and this site as the curated index.
- Lead with the three strongest quantitative/trading artifacts.
- Preserve honest attribution and limitations.
- Avoid generic developer-portfolio gimmicks.
- Work without a build step or external JavaScript dependencies.

## Deployment

This repository is configured for GitHub Pages at:

https://sohanhajra.github.io/

## Main files

- `index.html` — recruiter-facing homepage
- `research/` — project detail pages
- `assets/styles.css` — full responsive styling
- `assets/Sohan_Hajra_Resume.pdf` — résumé linked from the site
- `assets/favicon.svg` — site mark
- `.nojekyll` — serve files directly on GitHub Pages

Project claims are grounded in the current résumé, public LinkedIn profile, and the public GitHub repositories.
